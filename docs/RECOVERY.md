# 出错时如何恢复

1. 先停止转换和写入程序，在 R7 里选择内置照片风格「标准」。若是取景异常，先看它是否恢复。
2. 退出 EOS Utility，断开 USB、关机再开机，检查机身有无报错。不要在两个程序同时连接相机时重试写入。
3. `local/camera-before/` 是安装前快照，`local/install-*/` 是单槽安装器当次的备份与日志。若日志出现 `rollback`，看 `readbackExact` 是否为 `true`。任何返回非零或读回失败，都不要把它当成安装成功。
4. 若所选自定义槽位异常，用佳能官方 EOS Utility 的「相机设置 → 注册照片风格文件」给该槽位重新注册一份先前能正常工作的 PSE 文件。再切换回「标准」确认画面。
5. 如内置「标准」也持续报错，停止实验，按佳能官方售后与手册排查机身。不要继续尝试未知固件文件。

研究早期用零填充 PF3 曾出现 Err 10 与黑屏；切回内置标准、撤下测试风格后相机恢复。现在代码要求真实 PSE 模板、精确机型快照和指定版本解析器，但这些检查不能保证所有情况下都能恢复。
